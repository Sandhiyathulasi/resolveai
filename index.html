Transparent AI Architecture & System Design

Technical Disclosure

1. How the Current AI Engine Works (Rule-Based NLP)

In this demonstration, SmartResolve AI uses an explainable, deterministic natural language keyword matching and heuristic prioritization algorithm. When a student enters a complaint, the engine parses the text against curated facility dictionaries:

  • Water: detects terms like leak, tap, pipe, washroom, toilet, sink, overflow, drinking water.
  • Electricity: detects terms like power, spark, switch, socket, blackout, bulb, fan, wiring, shock.
  • Wi-Fi: detects terms like internet, network, router, portal, slow, latency, captive portal, DNS.
  • Cleanliness: detects terms like garbage, trash, dustbin, smell, pest, insects, sanitary, hygienic.
  • Maintenance: detects terms like broken door, lock, chair, desk, bench, elevator, window, paint.

2. Urgency & Priority Detection Rules

Priorities are evaluated using safety and disruption risk indicators:

🚨 High Priority

Triggered by hazard or emergency keywords (e.g., spark, electric shock, fire, flood, burst pipe, dangerous). Action dispatched immediately.

⚠️ Medium Priority

Triggered by operational disruption terms (e.g., not working, exam tomorrow, foul odor, frequent disconnect). Resolution within 24-48 hrs.

ℹ️ Low Priority

Routine requests, cosmetic fixes, minor squeaks, or general inquiries without safety disruption. Resolution within 3-5 business days.

3. Transitioning to a Large Language Model (LLM) Backend

The codebase is designed with a clean, decoupled asynchronous interface in js/aiAnalysis.js. To connect a production generative AI model (such as Google Gemini, Claude, or OpenAI), you can replace the internal rule engine with a secure backend API call: 

// In js/aiAnalysis.js - Simply forward to your secure backend endpoint:
async function analyzeComplaint({ title, description, location }) {
  const response = await fetch('/api/complaints/analyze', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ title, description, location })
  });
  return await response.json();
}

4. Privacy & Security Safeguards

  • Zero Third-Party Data Leakage: In this client-side demonstration, complaints remain strictly inside your browser's localStorage.
  • No Hardcoded API Keys: In adherence to web application security best practices, no secret API tokens or passwords are stored in frontend files.
  • Demo & Auditing Controls: Administrators can reset, seed, or backup complaints with full data ownership.
